How candidates get tested

A page cannot read another site's response on its own, so this borrows public read-only relays. They need no setup but are rate limited, so long runs crawl.

  1. Open console.cloud.google.com and make a project.
  2. Under APIs & Services, enable Google Drive API.
  3. Under Credentials, create an API key.
  4. Restrict it to your Pages address so nobody else spends your quota.

The key stays in this page and goes only to Google. It finds folders shared with anyone-who-has-the-link. A folder locked to named people looks missing to the key, which is why the relays stay switched on alongside it.
